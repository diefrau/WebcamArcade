# 모바일 프로파일

| 장치 | OS/브라우저 | 카메라/방향 | 현재 상태 |
|---|---|---|---|
| Samsung Galaxy S21 | One UI 7.0 / Android 15 (AP3A.240905.015.A2) / Chrome 156.0.8078.73 | 실제 카메라 설정·방향 미확인 | 실기기 프로파일 미실행 |
| Windows PC | Windows 11 / Chrome 156 | 실카메라 640×480, 30fps | 게임별 10초 탐색 측정 |

필요: 실측 참여, HTTPS 또는 USB 디버깅을 통한 안전한 접속, 카메라 권한, 동일 조명·거리·전원·발열 조건. 실카메라 동의 여부와 개인정보 보존 정책을 확인한다. 동영상 녹화·외부 업로드는 수행하지 않는다. 새 게임 둘은 이전 빌드와 비교할 수 없다. Chrome 기기 에뮬레이션은 Galaxy의 카메라·GPU·발열을 대체하지 않는다.

사용자 제보: 손가락을 사용하는 게임 전반에서 손 인식 불량. 구체적 재현 행동·인식 기대값 및 실측 성공/실패 횟수는 아직 확보하지 못했다.

사용자는 현재 Galaxy S21을 USB로 연결하기 어렵다고 응답했다. 실기기 계측은 수행하지 않았다.
