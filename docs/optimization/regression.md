## 같은 합성 랜드마크의 손 제스처 해석 비교

`node docs/optimization/compare-landmarks.mjs`는 두 SHA의 실제 `GestureInterpreter`에 같은 합성 좌표와 100ms 간격을 적용한다. 출력은 감지·핀치·발사·커서 위치이며 게임 전체 점수나 영상 추론 결과는 포함하지 않는다. 일반 펴기→핀치→유지→펴기 16개, 좌표 떨림 20개, 추적 유실 16개에서는 출력 차이 0개였다. 비정상적으로 작은 손바닥 입력 16개에서는 16개 모두 차이가 났다. 현재 코드는 작은 손바닥을 유실 처리하도록 변경되어 있으며 정상 사용자의 거리와 무관하다고 보장하거나 인식 저하 원인으로 단정할 수 없다. 전체 게임 판정과 실제 인식 정확도 비교는 여전히 미완료다. 원시 결과 `raw/landmark-synthetic.json`.

## 원 점수 합성 입력 비교

연속된 원, 열린 원, 타원, 적은 점 등 6개 입력에서 점수와 정확도가 같았다. 획 분리 표시가 있는 입력은 436점/44%와 432점/43%로 달랐으며, 이전 버전에는 획 분리 의미가 없으므로 직접적인 회귀 증거는 아니다. 실제 웹캠 정확도와 전체 게임 이벤트는 미검증이다. 원시 결과: `raw/circle-score-fixtures.json`.
