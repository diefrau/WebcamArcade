# 진단과 계획

현재 확인된 인식 저하/지연 원인: 없음. 코드 차이와 성능의 인과관계는 아직 증명되지 않았다.

| 가설 | 증거 | 반증·한계 | 다음 검증 |
|---|---|---|---|
| 홈 결합 인식 부하/체감 차이 | 기준은 손 1개, 현행 PC 홈은 두 손·얼굴 Worker와 복사, 최소 84ms 간격 | 게임 경로는 해당 홈 Worker를 사용하지 않음; 기기 측정 없음 | PC 홈에서 동일 조건 시간/부하 측정 및 게임과 분리 |
| stale 결과 무효화 | 현재 900ms 이상 결과 폐기, 기준에는 없음 | 느린 Worker가 실제로 900ms 넘는지 미측정, 안전 보호 의도 있음 | 느린 실제 실행에서 결과 age 분포 및 빈 입력 시간 |
| 중복 추론 | 가설 | busy 플래그와 Worker의 동기 `detectForVideo` 존재 | in-flight 최대값·정리 테스트 실측 |
| React 갱신 비용 | Context에 프레임별 결과 state | commit 비용·병목 미측정 | 프로파일러 별도 실행과 계측 오버헤드 검증 |
| 인식 자체 저하 | 사용자 관찰 | 기준 3게임/현행 조작·게임 로직 변경, 같은 실영상/정답 없음 | 동의한 동일 입력·실제 카메라로 누락/오검출 분리 |

수정 전 수용 기준: 각 게임의 기존 이벤트·점수·타이머·입력·오디오 보존, 실제 장치별 반복 측정의 잡음 및 인식 회귀 기준을 사용자가 제공한 시나리오와 기준선으로 먼저 확정한다. FPS 목표나 허용 오검출률은 임의로 정하지 않는다. 원인 확인 전 제품 코드 변경/리팩터링 금지.

추가로 과거와 현재의 GestureInterpreter를 비교한 결과, 손바닥 폭이 0.015 미만인 랜드마크를 현재는 추적 상실로 처리한다. 이는 기존 안전 처리이며 원거리 손에서 영향을 줄 가능성은 있지만, 실제 랜드마크 분포와 재현 실험 없이 원인이라고 단정할 수 없다. 원 그리기 입력 역시 기준 이후 사용자가 요청한 핀치·완료 동작으로 변경되었다.
