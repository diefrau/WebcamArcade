# 현황 보고

저장소와 두 SHA를 조사하고 프로덕션 빌드 및 합성 입력 비교, Windows 실카메라 예비 비교를 수행했다. 실제 카메라에서 쏴!, 원 그리기, 참!참!참!을 버전별 한 번씩 약 10초 측정했다. 사용자는 이번 Windows 비교에서 현재 버전이 더 좋게 느껴졌다고 응답했다. 이 계측은 추론 결과 수신까지의 시간이며 인식 성공률이나 센서→화면 지연을 측정하지 않는다. 게임 동작과 규칙이 버전별로 일부 다르다. 세부 값과 한계는 baseline.md에 기록했다.

확인된 성능 저하 원인이나 인식률 개선은 아직 없다. 동일 입력의 정답·정확도 기준, 반복과 장시간 검증, 계측 오버헤드 및 Galaxy S21 실측이 남아 있다. 사용자는 현재 S21 USB 연결이 어렵다고 했다. 따라서 요청된 측정 게이트를 충족하지 못했고 제품 코드 리팩터링·모델 변경·배포는 수행하지 않았다.

회귀 상태는 regression.md, 원인 가설은 diagnosis.md, 재현 명령은 commands.md, 모바일 제한은 mobile-profile.md를 참조한다. 6845125에는 게임 3종만 있어 현재 게임 5종 전체의 과거 비교는 불가능하다.
